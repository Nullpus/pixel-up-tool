# Pixel UP

ドット絵を**ぼかさずに**拡大するWebツールです。補間をしないので、色が増えたりにじんだりしません。
ビルド不要の静的ファイル(HTML / CSS / JavaScript)のみで、画像はすべてブラウザ内で処理されます(外部には送信されません)。

## 使い方

1. `index.html` をブラウザで開く(サーバー不要)
2. 画像をドラッグ&ドロップ、クリックで選択、または `Ctrl+V` で貼り付け
3. 拡大方式と倍率(またはサイズ)を選ぶ
4. 「PNGとして保存」

## 機能

### 拡大方式

| 方式 | 説明 |
| --- | --- |
| ニアレストネイバー | 1ドットを N×N の正方形に複製。最も忠実な整数倍拡大 |
| Scale2x | 既存の色だけを使って斜めの線を滑らかにする(AdvMAME2x)。2の累乗倍のみ |

### 指定方法

- **倍率で指定**: スライダー / 数値入力 / プリセットボタン
- **出力サイズで指定**: 幅×高さ(縦横比の固定も可能)
  - 指定サイズぴったりにする: 整数倍にならない場合はドット幅が1px単位で不揃いになります
  - 整数倍で最大化して余白(透明)で合わせる: ドットの形を保ったまま指定サイズに収めます
  - 元画像より小さいサイズ(縮小)は対象外です

### その他

- 拡大済みのドット絵から1ドットの大きさを自動検出し、等倍に戻して再拡大できます
  (JPEG圧縮ノイズやジャギーのある画像は検出できません)
- 出力は一辺 16384px 以下、かつ約 1.3 億ピクセル以下に制限されています
